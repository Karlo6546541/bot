# Subhasto redesign — 4 November 2026

The interface uses a shared neutral palette, system light/dark preference, consistent controls, simpler navigation and photo-first cards. Home recommendations now use the existing ranking and hidden-item preferences rather than stopping at six unranked listings. Live shows, auctions, digital products and followed sellers remain accessible. Profile, seller setup, Seller Hub, activity, search, messages, empty states and purchase actions use the same visual system. The narrow-screen purchase bar no longer overflows, including at 150% text size.

Seller details save independently of Stripe onboarding. Local private data is persisted first; cloud success is reported only after the current seller/profile writes finish. Rejected or interrupted writes remain queued and can be retried. An anonymous initial RLS response no longer erases the current user's cached seller record. Seller Hub and Profile distinguish local pending writes, saved details, provider errors and actual Stripe readiness. Saving never opens an external Stripe page; the existing connect action and publishing eligibility still use Stripe's real status. No verification, payout account, or terms acceptance is fabricated.

Stripe Connect additionally rejects a request whose expected app user differs from the authenticated user. It remains test-only, pinned to the existing platform, with its own JWT authentication and existing restricted/shared-test onboarding compatibility. Deployment v10 changes only this owner guard over v9; deployed shared helpers and Vault configuration are preserved.
