## Interface

- Black default canvas, cool glass surfaces, soft white typography, blue secondary actions and gold live prices. Explicit light/system preferences still work.
- Home: wordmark with search/messages/notifications/filters, capsule Live/Shop/Following filters, a large live stage and smaller photo broadcasts. Upcoming shows remain available below. Existing ranking and filters are retained.
- Floating rounded navigation keeps categories, seller tools, purchases and profile available. Desktop keeps its navigation rail.
- Live: video stays central; one bounded glass dock contains the current item, authoritative countdown and existing bid actions. Shop opens above the running broadcast. More tools, moderation, sharing, giveaways, custom bids and host controls remain available.
- Shop: translucent product rows and compact identity. Own profile displays the real shop before account tools. Seller actions and account status use the same visual system.
- Forms, messages, orders, settings, dialogs and purchase confirmation inherit consistent rounded controls and surfaces. Purchase still uses the existing saved-card confirmation, delivery rules and server payment result.
- Blur is limited to navigation, live dock and open live catalog; scrolling product lists use normal surfaces. Reduced-motion users receive a static surface.
- A small live status panel can scroll when keyboard/screen constraints leave little space; the central prompt is hidden while composing chat.
